# Project Plan

## Current Phase

**Research and Literature Review Completed — Brain Planning and Knowledge-Source Analysis in Progress**

## Planned Workstreams

1. Conduct and document the literature review.
2. Identify research gaps and refine the problem statement.
3. Define source-selection and knowledge-base practices.
4. Refine the high-level architecture and system boundaries.
5. Design the AI Brain as the core intelligent component of the system.
6. Develop a curated, source-grounded knowledge base focused on the Ganga, river conservation, environmental awareness, and related topics.
7. Design and implement a Retrieval-Augmented Generation (RAG) pipeline for retrieving relevant information and generating source-grounded responses.
8. Investigate suitable authoritative real-time data sources and APIs for questions requiring current environmental information.
9. Develop a hybrid knowledge-routing approach that can determine whether a query should use:
   - Static knowledge through RAG.
   - Real-time information through an approved API or data source.
   - A combination of both.
10. Implement source attribution and provenance tracking so responses can be connected to the information used to generate them.
11. Implement grounding and fallback behaviour so the Brain does not fabricate unsupported information and clearly explains why a reliable answer cannot be provided when the required information is unavailable.
12. Develop basic conversational context handling for follow-up questions.
13. Develop educational interaction capabilities such as simplified explanations, quizzes, and conservation-oriented responses.
14. Expose the Brain through a modular interface/API for integration with the other project components.
15. Develop the digital avatar and interaction components.
16. Develop voice-based interaction and connect it with the Brain and avatar.
17. Integrate the Brain, avatar, voice, and user-facing components into a unified system.
18. Evaluate the system for retrieval quality, response correctness, grounding, real-time data handling, fallback behaviour, response time, usability, engagement, and educational usefulness.
19. Document the final architecture, implementation, experiments, results, limitations, and future work.

## Completed Work

- Literature review conducted.
- Initial set of relevant research papers identified and analysed.
- Existing related projects and approaches reviewed.
- Research gaps and potential areas for improvement identified.
- RAG identified as a suitable foundation for the source-grounded Brain.
- Initial Brain requirements defined.
- Initial project architecture and component boundaries established.

The project will proceed from the finalized research and planning into implementation of the Brain, knowledge base, real-time data integration, conversational and educational capabilities, followed by avatar, voice, system integration, evaluation, and final documentation.

The sequence and scope may change as the academic work develops.
